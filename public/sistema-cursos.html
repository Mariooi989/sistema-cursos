01 — Qué somos

Una plataforma para aprender
de forma simple y flexible.

Somos una plataforma de cursos online orientada a facilitar el acceso a la capacitación digital. Nuestro sistema permite explorar cursos, consultar contenidos, inscribirse y avanzar en el aprendizaje según el ritmo de cada usuario.

🎓

Aprendizaje online

Acceso a cursos desde cualquier dispositivo, sin depender de horarios fijos.

📚

Contenido organizado

Cursos divididos en clases, módulos y materiales para avanzar paso a paso.

🚀

Enfoque práctico

La propuesta está pensada para aplicar los conocimientos en situaciones reales.

02 — Objetivo

Nuestro objetivo es acercar
la formación a más personas.

Buscamos ofrecer una experiencia de aprendizaje clara, accesible y moderna, donde cada usuario pueda encontrar cursos útiles para mejorar sus conocimientos, desarrollar nuevas habilidades y avanzar en su formación personal o profesional.

La plataforma conecta usuarios con cursos digitales, permitiendo gestionar inscripciones, progreso, clases, comentarios y contenidos desde un mismo sistema.

04 — Stack Tecnológico

Las herramientas
del sistema.

Cada herramienta cumple un rol específico en la arquitectura del sistema.

🐘
PHP 8.2
Lenguaje del servidor. Corre a través de XAMPP con soporte para extensiones modernas.
⚡
Laravel 11
Framework principal. Gestiona rutas, controladores y conexiones a bases de datos con Eloquent ORM.
🗄️
MySQL
Base de datos relacional. Almacena cursos, usuarios, clases e inscripciones en tablas relacionadas.
🍃
MongoDB Atlas
Base de datos no relacional en la nube (plan gratuito M0). Almacena comentarios como documentos JSON.
📦
Composer
Gestor de paquetes de PHP. Instala Laravel y todas sus dependencias, incluyendo laravel-mongodb.
🧪
Postman
Testing de endpoints. Permite enviar requests HTTP y visualizar respuestas JSON sin necesitar un frontend.
