MongoDB básico

Conocé los fundamentos de MongoDB y las bases de datos no relacionales. En este curso vas a aprender a trabajar con documentos JSON, colecciones, consultas básicas y estructuras flexibles para aplicaciones modernas.

01 — Temario

Qué vas a aprender
en este curso.

El contenido está organizado para comprender cómo funcionan las bases de datos no relacionales y cómo se pueden usar en proyectos web modernos.

Módulo 01

Introducción a NoSQL

Diferencias entre bases de datos relacionales y no relacionales. Cuándo conviene usar MongoDB y qué problemas permite resolver.

Módulo 02

Documentos y colecciones

Organización de datos mediante documentos JSON, colecciones, campos flexibles y estructuras anidadas.

Módulo 03

Consultas en MongoDB

Inserción, búsqueda, actualización y eliminación de documentos usando consultas básicas de MongoDB.

Módulo 04

MongoDB Atlas

Uso de MongoDB en la nube, creación de clusters, conexión con aplicaciones y manejo básico desde un backend.

02 — Requisitos

Qué necesitás
para empezar.

Conocimientos básicos de programación o desarrollo web.
Tener una cuenta gratuita en MongoDB Atlas o crearla durante el curso.
Editor de código, preferentemente Visual Studio Code.
Interés en aprender bases de datos flexibles basadas en documentos JSON.
03 — Orientación

A quién está dirigido
este curso.

Este curso está orientado a personas que quieren conocer una alternativa moderna a las bases de datos relacionales, especialmente para aplicaciones que manejan datos flexibles, comentarios, reseñas, perfiles, catálogos o información variable.

🍃

Para aprender NoSQL

Ideal para quienes quieren entender cómo se almacenan datos sin usar tablas tradicionales como en MySQL.

🧩

Para datos flexibles

Vas a aprender a trabajar con documentos que pueden tener estructuras distintas según las necesidades del sistema.

☁️

Para proyectos en la nube

El enfoque incluye MongoDB Atlas, una plataforma en la nube que permite usar MongoDB sin instalar un servidor propio.
