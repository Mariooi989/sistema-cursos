01 — Temario

Qué vas a aprender
en este curso.

El contenido está organizado para avanzar desde los conceptos básicos hasta la construcción de una API REST funcional con Laravel.

Módulo 01

Introducción a Laravel

Instalación, estructura del proyecto, rutas principales y configuración inicial.

Módulo 02

Rutas y controladores

Creación de endpoints, organización de la lógica y respuestas en formato JSON.

Módulo 03

Modelos y base de datos

Uso de Eloquent, migraciones, tablas, relaciones y conexión con MySQL.

Módulo 04

API REST

Creación de operaciones para listar, guardar, modificar y eliminar recursos.

02 — Requisitos

Qué necesitás
para empezar.

Conocimientos básicos de HTML y PHP.
Tener instalado XAMPP o un entorno similar.
Editor de código, preferentemente Visual Studio Code.
Ganas de practicar y construir un proyecto real.
