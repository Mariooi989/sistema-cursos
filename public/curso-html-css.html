01 — Temario

Qué vas a aprender
en este curso.

El contenido está pensado para que puedas crear páginas web simples, ordenadas, visualmente atractivas y adaptables a distintos tamaños de pantalla.

Módulo 01

Estructura HTML

Etiquetas básicas, estructura de un documento, encabezados, párrafos, enlaces, imágenes, listas y secciones.

Módulo 02

Estilos CSS

Selectores, colores, tipografías, márgenes, bordes, fondos, tamaños y organización visual de los elementos.

Módulo 03

Diseño responsive

Uso de flexbox, grid y media queries para adaptar una página web a computadoras, tablets y celulares.

Módulo 04

Formularios y componentes

Creación de formularios, botones, tarjetas, barras de navegación y secciones reutilizables para una página web.

02 — Requisitos

Qué necesitás
para empezar.

No necesitás experiencia previa en programación.
Tener instalado Visual Studio Code o un editor de texto similar.
Contar con un navegador web para probar las páginas.
Ganas de practicar creando una página web desde cero.
03 — Orientación

A quién está dirigido
este curso.

Este curso está orientado a personas que quieren iniciarse en el desarrollo web, crear sus primeras páginas, comprender cómo se estructura un sitio y aprender a darle estilo con CSS.

🌐

Para principiantes

Ideal para quienes quieren empezar desde cero y entender cómo se construye una página web paso a paso.

🎨

Para diseño visual

Vas a aprender a aplicar colores, tipografías, espaciados y estilos para mejorar la presentación de una página.

📱

Para páginas responsive

El curso incluye técnicas para que tus páginas se vean correctamente en distintos dispositivos.
