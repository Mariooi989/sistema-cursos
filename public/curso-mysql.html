01 — Temario

Qué vas a aprender
en este curso.

El contenido está pensado para que puedas comprender cómo se organizan los datos en una base relacional y cómo consultarlos mediante SQL.

Módulo 01

Introducción a bases de datos

Conceptos básicos de bases de datos, tablas, registros, campos, tipos de datos y organización de la información.

Módulo 02

Consultas SQL

Uso de SELECT, WHERE, ORDER BY, INSERT, UPDATE y DELETE para consultar y modificar información.

Módulo 03

Relaciones entre tablas

Claves primarias, claves foráneas, relaciones uno a muchos y diseño de modelos relacionales.

Módulo 04

JOIN y consultas avanzadas

Consultas combinadas entre tablas, uso de INNER JOIN, LEFT JOIN y obtención de información relacionada.

02 — Requisitos

Qué necesitás
para empezar.

Conocimientos básicos de computación.
Tener instalado XAMPP, MySQL Workbench o un entorno similar.
Editor de código, preferentemente Visual Studio Code.
Ganas de practicar consultas y diseñar bases de datos reales.
03 — Orientación

A quién está dirigido
este curso.

Este curso está orientado a personas que quieren aprender a crear, consultar y administrar bases de datos para proyectos web, sistemas de gestión, aplicaciones administrativas o APIs.

🗄️

Para futuros desarrolladores

Ideal para quienes necesitan comprender cómo se guardan y relacionan los datos dentro de una aplicación.

🔎

Para aprender SQL

Vas a practicar consultas para buscar, filtrar, ordenar, insertar, modificar y eliminar información.

📊

Para sistemas reales

El enfoque está pensado para aplicar MySQL en sistemas de cursos, bibliotecas, ventas, usuarios o inscripciones.
